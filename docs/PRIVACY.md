# 隐私与数据

课序在当前 Windows 用户的 `%LOCALAPPDATA%\CourseDesk` 保存课表、偏好、备份及日志。OCR 使用 Windows 本地能力，不将课表发送到远程识别服务。应用不包含云同步、账号登录或遥测。

文件未加密，拥有用户目录读取权限的人可以看到它们。备份保留最近 30 份，因此删除一门课不会立即从历史备份中抹去。导出文件与截图也可能包含个人信息，请自行决定分享范围。

公开源码与发布包不包含创作者的个人课表、偏好、日志、原始截图或备份。演示截图与 `examples/` 使用虚构课程，不会自动加载到新用户课表中。

软件中的链接会通过默认浏览器打开外部网站，Windows 通知与任务由系统管理，其行为受你的系统设置影响。
