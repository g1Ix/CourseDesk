# 课序 1.0

创作者：**g1Ix** · 原创代码版权所有 © 2026 g1Ix

首个公开版本，提供 Windows 中文桌面课表管理、图片 / PDF 本地 OCR、重复与临时课程编辑、周视图、自动备份和默认 23:55 的明日课程提醒。

## 下载

下载 `CourseDesk-1.0.0-Windows-x64.zip`，完整解压，双击 `CourseAssistant.exe`；无需另装 Python。需要每日提醒时运行同目录的 `install_task.ps1`。

新用户首次打开是空课表。发布包不包含个人课程、设置或备份；项目演示数据均为虚构。已有用户的本地数据保留，移动程序后需重装提醒任务以更新路径。

`SHA256SUMS.txt` 可用于核对压缩包完整性。该便携版未做代码签名。

## 限制

目标为 Windows 10 / 11 x64，本地桌面验收使用 Windows 11。OCR 需要对应 Windows 语言能力，识别结果必须校对。电脑关机、未登录或通知被系统抑制时不能即时提醒；补运行查询运行时的下一日。

详细说明见仓库 README、USER_GUIDE 和 THIRD_PARTY_NOTICES。
